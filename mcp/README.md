# Native-client MCP adapter

Runtime: `python -m opencraft_server.mcp`, official SDK 2.1.1, stdio only.
Configure Codex OR Claude Code independently using [the client guide](../docs/NATIVE_CLIENTS.md).
This adapter delegates to CanonicalWorldService; it is not another authorization
system and cannot bypass preview, revision, consent, idempotency or provenance.

Tools: get_context, get_history, preview_build, get_preview, request_commit,
undo_agent_transaction (all prefixed `opencraft_`). Context is also a resource at
`opencraft://world/context`. `--read-only` exposes only the first two tools.
The actual input schema is generated by the SDK; tools.catalog.json is a summary.

Human confirmation is resolver-injected, not model-supplied. Declined/cancelled or
unsupported forms do not commit. The SDK handles current and legacy protocol
transport negotiation, including authenticated multi-round request state.
There is no voice, credential, arbitrary Python, shell or filesystem MCP tool.

The legacy `--discover` option prints a reference contract; it does not start a
server. The actual default runtime is stdio, not an HTTP MCP endpoint. Public MCP
hosting is out of scope and requires separate authentication and security review.
