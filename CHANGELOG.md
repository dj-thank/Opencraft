# Changelog

All notable changes are documented here. OpenCraft has not made a stable release.

## 0.16.0-dev.1 — unreleased

### Added

- Canonical world reference model with bounded agent plans, revision checks, idempotent atomic commits, provenance, and safe undo.
- Preview-bound, actor/agent/world/revision-bound, single-use consent.
- Privacy-filtered agent context envelope and least-privilege WebMCP tool publication.
- MCP 2026-07-28 discovery and transport-header reference checks.
- World-first lobby/world shell and voice consent state model.
- Blender 4.2+ extension manifest, declarative spool protocol, and main-thread allowlisted proxy operations.
- Source-controlled quality workflow, JavaScript tests, contribution rules, architecture, security, and release documentation.

### Changed

- Replaced the failed ephemeral archive-import approach with ordinary source-controlled development.
- Renamed the integrated project surface from BlendWorld prototypes to OpenCraft.

### Not included

- Production hosting, live WebRTC voice, a real LLM provider, proven Cloudflare parity, Blender multi-instance E2E, signed installers, or General Release evidence.
