# Support

OpenCraft is a Developer Preview. Questions, reproducible bugs, UX feedback, and proposals may be filed as GitHub issues.

Before filing:

1. Search existing issues.
2. Include operating system, Python/Node/Blender version, exact revision, reproduction steps, expected result, and actual result.
3. Remove tokens, private world data, voice recordings, personal information, and proprietary assets.

Security or privacy vulnerabilities must follow `SECURITY.md`, not a public issue.

The project does not yet offer production support, service-level guarantees, hosted-world recovery guarantees, or compatibility guarantees for unpublished protocols.
