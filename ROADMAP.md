# OpenCraft roadmap

## P0 — Closed-alpha evidence

- Real canonical server ↔ browser integration
- Two-client presence, resume, preview, consent, commit, and undo E2E
- Blender 4.2+ extension installation and two-instance synchronization
- Cloudflare staging deployment with parity tests
- Owner authentication, recovery, and session revocation

## P1 — Social world

- Avatar import and safe conversion pipeline
- WebRTC Lobby / Spatial / Hybrid voice
- TURN fallback and device diagnostics
- Object cards, tours, follow, party, block, and report flows

## P2 — Agent construction

- One real provider adapter behind the provider-neutral planner boundary
- MCP and WebMCP interoperability tests
- Background jobs with budgets, cancellation, and provenance
- Isolated Blender worker and quarantined asset pipeline

## P3 — Distribution

- Signed Windows installer
- Notarized macOS application and DMG
- Clean-machine installation tests
- Non-technical usability study
- Independent security and privacy review
